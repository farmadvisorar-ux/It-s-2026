Questions

Is it really free?

Yes. A permanent listing and a spot on the daily board cost nothing. Paid tiers only add a featured slot and a backlink.

What counts as a micro-SaaS?

Any small, focused software product — a single-purpose tool, a niche API, a Chrome extension, a solo-founder app. If it solves one problem well, it belongs here.

How do you rank products?

Purely by community upvotes over the launch day. At midnight the board resets and the winners get archived into the permanent directory.

Do you sell my email?

Never. We use it only to send you launch-day updates for your own submission. See the security notes in the repo for how data is handled.
